# MTG Card PDF Web App

Flask web app to upload images, adjust crop/rounding, and generate a 3.5"×3.5" card PDF.

## Setup

```bash
python -m venv venv
venv\Scripts\activate   # Windows
# source venv/bin/activate  # macOS/Linux
pip install -r requirements.txt
```

## Run

```bash
python app.py
```

Open http://127.0.0.1:5000 in your browser.
